이제 기사를 챗봇에 붙여넣지 마세요. Safari를 떠나지 않고 어떤 페이지든 AI에게 묻고, 읽으면서 메모하세요. 채팅은 페이지에서 페이지로 따라오고, 같은 채팅이 iPhone, iPad, Mac에도 있어요. 요약, 핵심 사실 정리, 페이지 전체 번역도 복사나 앱 전환 없이 할 수 있어요.

할 수 있는 일
• 기사, 리뷰, 스레드, 상품 페이지를 몇 초 만에 요약
• 핵심 내용, 숫자, 날짜를 한눈에 확인
• 직접 질문하기: “함정은 뭐야?”, “살 만한 가치가 있어?”, “다음엔 뭘 해야 해?”
• 전문 용어와 복잡한 주제를 쉬운 말로 설명
• 페이지를 내 언어로 번역
• 텍스트를 선택해 그 부분만 직접 질문하거나 메모로 남기기
• Google 답변: Google 검색의 최신 정보를 번호가 매겨진 출처와 함께 제공

메모와 채팅
• 메모: 보내기 버튼을 위나 아래로 쓸어 넘기면(Mac에서는 버튼 위에서 스크롤) 질문 대신 메모를 쓸 수 있어요. 메모는 해당 페이지와 함께 채팅에 남고 답변 횟수를 쓰지 않아요
• 새 채팅을 시작하기 전까지 하나의 채팅이 사이트를 넘나들며 이어지고, 채팅 속 페이지마다 방문한 날이 표시돼요
• 채팅 전체: 켜면 모든 메시지, 메모, 채팅의 모든 페이지를 반영해 답변해요
• 태그: 채팅, 답변, 메모에 태그를 달고, 태그로 필터링하거나 채팅을 폴더로 묶으세요
• 어떤 단어로든 채팅을 검색하세요. Safari에서도, 앱에서도요
• 중요한 채팅은 고정하고, 이름을 바꾸고, 채팅이 거쳐 간 페이지 목록을 확인하세요. 탭하면 그 페이지로 돌아가요
• 어떤 답변이나 메모든 복사하고, 공유하고, 태그를 달 수 있어요. 채팅 전체를 공유하거나 필요한 메시지만 골라 보내세요. 링크와 출처도 함께 가요

앱에서 보는 모든 채팅
• iPhone, iPad, Mac의 ContextFlow 앱에 Safari의 모든 채팅이 있어요
• 어떤 채팅이든 읽고, 그 채팅에 질문하거나 메모를 추가한 뒤 Safari에서 이어 가세요
• 채팅이 iCloud를 통해 iPhone, iPad, Mac 간에 동기화돼요

iPhone, iPad, Mac의 Safari를 위해 제작
• iPhone 및 iPad: 어떤 페이지에서든 ContextFlow 플로팅 버튼을 탭하거나, 선택한 텍스트에서 ‘AI에게 묻기’를 탭
• Mac: 도구 막대, 플로팅 버튼 또는 Control-Shift-E로 여는 사이드바
• 처음 실행할 때 짧은 둘러보기, 기능마다 짧은 동영상이 있는 앱 속 팁
• 라이트 및 다크 모드, 글자 크기 조절, 11개 언어 지원

설계부터 개인정보 보호
• 계정, 가입, 추적 없음
• 페이지는 사용자가 질문할 때만 읽어요
• 페이지 텍스트는 당사 서버에 절대 저장되지 않으며, 채팅은 내 기기에 남고 종단 간 암호화되어 iCloud로 동기화돼요. 동기화는 설정에서 끌 수 있어요

무료 및 Pro
• 무료: 가입 없이 매일 답변. 답변은 페이지의 텍스트를 바탕으로 하고, 페이지에 동영상이나 PDF가 있으면 그 부분은 건너뛰었다고 알려 줘요. 답변을 다 쓰면 새 답변이 언제 생기는지 정확히 보여 주고, 메모는 계속 무료이며 무제한이에요
• Pro: 넉넉한 답변 횟수와 더 깊고 자세한 답변, 페이지 속 동영상과 PDF에 대한 질문, 내 말로 설명하면 채팅을 찾아 주는 AI 검색, 모든 채팅을 바탕으로 답하는 ‘모든 채팅에 묻기’까지, 모든 Apple 기기에서
• 내 키: 내 OpenAI 또는 Claude API 키로 답변 무제한

1. ContextFlow 앱을 열면 Safari에서 확장 프로그램을 켜는 방법을 단계별로 보여 줘요.
2. 아무 웹사이트나 열고 ContextFlow 버튼을 탭하세요(Mac에서는 도구 막대의 ContextFlow 아이콘을 클릭).
3. 요약, 핵심 정리, 쉽게 설명, 번역 중에서 선택하거나 그냥 질문하세요.
