ContextFlow는 Safari 안에서 바로 쓰는 AI 어시스턴트예요. 긴 기사를 요약하고, 핵심 사실을 뽑아내고, 무엇이든 쉬운 말로 설명하거나 페이지 전체를 번역해요. 복사, 붙여넣기, 앱 전환은 필요 없어요.

할 수 있는 일
• 기사, 보고서, 스레드, 상품 페이지를 몇 초 만에 요약
• 핵심 내용, 숫자, 날짜를 한눈에 확인
• 직접 질문하기: “함정은 뭐야?”, “살 만한 가치가 있어?”, “다음엔 뭘 해야 해?”
• 전문 용어와 복잡한 주제를 쉬운 말로 설명
• 페이지를 내 언어로 번역
• 텍스트를 선택해 설명 듣기, 글 다듬기, 답장 초안 작성

iPhone, iPad, Mac의 Safari를 위해 제작
• iPhone 및 iPad: 어떤 페이지에서든 ContextFlow 플로팅 버튼을 탭
• Mac: 도구 막대에서 또는 Control-Shift-E로 여는 사이드바
• 페이지마다 대화가 따로 저장되어 나중에 이어서 볼 수 있어요
• 라이트 및 다크 모드, 11개 언어 지원

설계부터 개인정보 보호
• 계정, 가입, 추적 없음
• 페이지는 사용자가 질문할 때만 읽어요
• 페이지 텍스트는 당사 서버에 절대 저장되지 않으며, 채팅은 기기에만 남아요

무료 및 Pro
• 무료: 매일 답변 5개
• Pro: 모든 Apple 기기에서 매주 최대 375개 답변
• 내 키: 내 OpenAI 또는 Claude API 키로 답변 무제한

1분 만에 시작하기
1. ContextFlow 앱을 열고 안내에 따라 Safari에서 확장 프로그램을 켜세요.
2. 아무 웹사이트나 열고 ContextFlow 버튼을 탭하세요(Mac에서는 도구 막대의 ContextFlow 아이콘을 클릭).
3. 요약, 핵심 정리, 쉽게 설명, 번역 중에서 선택하거나 그냥 질문하세요.
