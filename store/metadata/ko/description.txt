이제 기사를 챗봇에 붙여넣지 마세요. Safari를 떠나지 않고 어떤 페이지든 AI에게 묻고, 그 자리에서 번역하고, 스스로 채워지는 템플릿으로 답장하세요. 채팅은 페이지에서 페이지로 따라오고, 같은 채팅이 iPhone, iPad, Mac에도 있어요.

2.7의 새로운 기능
• 페이지를 그 자리에서 번역: 텍스트가 제자리에서 바뀌고 링크도 그대로 작동해요. 한 번 탭하면 사이트 전체가 번역돼요
• 컬렉션: 여행이나 구매처럼 한 가지 일에 필요한 모든 것을 한곳에. Pro에서는 AI가 섹션으로 나누고, 카드를 표로 비교하고, 전체를 요약해 줘요
• 스페이스: 업무, 개인, 쇼핑을 따로 관리해요. 스페이스마다 채팅과 색이 따로 있어요
• 사이트의 어떤 입력란에서든 페이지를 반영한 ‘검사’와 ‘다시 쓰기’: 더 짧게, 더 따뜻하게, 더 격식 있게, 더 자신 있게
• 채팅에서 바로 캘린더나 미리 알림에 추가하고, 메모에 페이지 스냅샷을 남기세요

할 수 있는 일
• 기사, 리뷰, 스레드, 상품 페이지를 요약하거나, 핵심 사실만 정리하거나, 전문 용어를 쉬운 말로 설명
• 직접 질문하기: “함정은 뭐야?”, “살 만한 가치가 있어?”
• 텍스트를 선택해 그 부분만 질문하거나 메모로 남기기
• Google 답변: Google 검색의 최신 정보를 열어 볼 수 있는 출처와 함께 제공
• 반복해서 쓰는 답장은 템플릿으로: 텍스트 필드를 탭하면 페이지 내용으로 채워져요
• 비슷한 것 찾기: 어떤 페이지든 실제로 있는 대안을 찾아 줘요. 더 저렴하게, 더 최신, 재고 있음, 내 언어로. 모든 링크를 확인해서 보여 줘요
• 듣기(Ultra): 답변과 페이지 전체를 자연스러운 목소리로 읽어 줘요
• 가격이 내리길 기다리나요? 가격을 선택하고 눈 아이콘을 탭하면 바뀔 때 ContextFlow가 알려 줘요

메모와 채팅
• 메모: 보내기 버튼을 위나 아래로 쓸어 넘기면(Mac에서는 버튼 위에서 스크롤) 질문 대신 메모를 쓸 수 있어요. 메모는 답변 횟수를 쓰지 않아요
• 채팅 전체: 모든 메시지, 메모, 채팅의 모든 페이지를 반영해 답변해요
• 스스로 정리되는 채팅(Pro): 새 답변이나 메모가 갈 곳을 ContextFlow가 추천하고, 채팅 이름도 주제에 맞춰 지어 줘요
• 태그, 폴더, 채팅 검색

앱에서 보는 모든 채팅
• iPhone, iPad, Mac의 ContextFlow 앱에 Safari의 모든 채팅과 컬렉션이 있어요. 읽고, 질문하고, 메모를 추가하세요
• 채팅과 템플릿은 iCloud를 통해 기기 간에 동기화돼요

iPhone, iPad, Mac의 Safari를 위해 제작
• iPhone 및 iPad: 어떤 페이지에서든 ContextFlow 플로팅 버튼을 탭하거나, 선택한 텍스트에서 ‘AI에게 묻기’를 탭
• Mac: 도구 막대, 플로팅 버튼 또는 Control-Shift-E로 여는 사이드바
• 짧은 동영상이 있는 팁, 라이트 및 다크 모드, 15개 언어 지원

설계부터 개인정보 보호
• 계정, 가입, 추적 없음
• 페이지는 사용자가 질문하거나 지켜볼 때만 읽어요
• 페이지 텍스트는 당사 서버에 절대 저장되지 않으며, 채팅은 내 기기에 남고 종단 간 암호화되어 iCloud로 동기화돼요

요금제
• 무료: 매일 답변, 하루 몇 번의 템플릿 채우기, 컬렉션 1개, 무제한 메모
• Pro: 넉넉한 답변 횟수와 더 깊고 자세한 답변, 동영상과 PDF, 무제한 템플릿 채우기, AI가 정리하는 컬렉션, 더 많은 페이지 지켜보기, AI 검색과 ‘모든 채팅에 묻기’
• Ultra: Pro의 모든 기능에 듣기, 더 넓게 검색하는 비슷한 것 찾기, 최대 50개 페이지 지켜보기까지
• 내 키: 내 OpenAI 또는 Claude API 키로 답변 무제한
• Pro, Ultra, 내 키: 월간 또는 연간

1분 만에 시작하기
1. ContextFlow 앱을 열면 Safari에서 확장 프로그램을 켜는 방법을 단계별로 보여 줘요.
2. 아무 웹사이트나 열고 ContextFlow 버튼을 탭하세요(Mac에서는 도구 막대의 ContextFlow 아이콘을 클릭).
3. 요약, 핵심 정리, 쉽게 설명, 번역 중에서 선택하거나 그냥 질문하세요.
