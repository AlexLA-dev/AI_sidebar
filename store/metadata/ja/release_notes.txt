ContextFlow 2.4 の新機能：
• iPhone、iPad、Mac のアプリで、すべてのチャットを見られるようになりました。検索したり、どのチャットにも質問したり、メモを追加したりできます
• タグ：チャット、回答、メモにタグを付けて、タグで絞り込んだり、チャットをフォルダにまとめたりできます。Safari でもアプリでも使えます
• 回答とメモの下に「コピー」「共有」とタグを表示。「チャットを共有」では送るメッセージを選べます
• チャット内の各ページに、そのページを見た日が表示されるようになりました
• テキストを選択したら：その部分について自分で質問するか、メモとしてチャットに残せます
• Pro では、ページ上の動画や PDF も読み取れるようになりました。AI検索は説明からチャットを見つけ、「すべてのチャットに質問」はすべてのチャットをもとに答えます。Pro がない場合はページのテキストをもとに回答し、動画や PDF を読み飛ばしたときはお知らせします
• かんたんセットアップ：「設定」で ContextFlow をオンにする手順をアプリがステップごとに案内し、完了していなければお知らせします
• 無料回答を使い切ったら：いつ戻るかが正確にわかり、メモは引き続き無料・無制限。Pro の最初の 1 か月は 50% オフになります
• 自分の API キーを使っている場合：アプリから直接 Pro に切り替えられるようになりました
• Mac では、アプリのメニューがお使いの言語で表示されるようになりました
• 修正と改善
