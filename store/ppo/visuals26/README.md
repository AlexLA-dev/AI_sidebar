# Тест страницы 2.6: новые скриншоты, баннеры и видео-превью

Это вариант для теста страницы продукта против текущего набора 2.5. Набор собран по разбору директора.
Правило владельца: Pro-функции показываем, если их ценность понятна с одной картинки, и подписываем «Pro».

Ни загрузки в ASC, ни эксперимента здесь нет: их делает директор после «да» владельца.

Что изменилось против 2.5:
- **Раскладка.** Каждое устройство видно целиком, вместе с панелью Safari. Раскладки разные: телефон по центру, слева или справа с увеличенной карточкой рядом, плавающее уведомление. Плашки стоят только под заголовком и не закрывают ни интерфейс, ни заголовок.
- **Pro.** Подписан чипом «Pro» над заголовком. «Get Pro» в панели и счётчик бесплатных ответов скрыты на всех кадрах.
- **Слежение (кадр 2).** Показана сама цена: старая и новая, и уведомление.
- **Копии (кадр 3).** Пять копий, без шаблонов. Поле действительно заполнено. Вместо «anywhere» — «в любом поле Safari». Строки «стирается через 24 часа» нет.
- **Шаблоны (кадр 4).** Заполненный результат крупно.
- **Ответы.** Кадр 5 показывает ответ. Ответы Google вернулись в набор. Кадр 10 показывает PDF.
- **Подсказки Pro «куда отнести»** в набор не вошли: на одной картинке без опыта работы с приложением их не объяснить, а «Videos and PDFs» объясняется.

**Уведомление на кадре 2.** iOS сама рисует баннер, в Chromium его не снять. Баннер нарисован так же, как сборщик рисует строку состояния и панель Safari. Иконка — настоящая иконка приложения. Текст тот, который отправляет приложение: `watchChanged` / `watchChangedBody` в `src/background/watch.ts`, «Changed: Price / Now: $99». В видео так же.

## Видео-превью (`store/previews/visuals26/<locale>/<iphone|ipad>.mp4`)

Папка в `.gitignore`: файлы по 30 МБ в репозиторий не кладём. Копия лежит в `~/ContextFlow-work/store-pages/shots26/vid/`.

- **Формат.** iPhone 886×1920, iPad 1200×1600. 30 fps, H.264 High 4.0, 10 Мбит/с, беззвучная стерео-дорожка AAC. Длина 24,0–24,6 с.
- **Сюжет:**
  1. пересказ;
  2. слежение за ценой, затем приходит уведомление о снижении;
  3. в поле вставляется последняя копия;
  4. шаблон заполняется со страницы;
  5. камера отъезжает к iPhone, iPad и Mac с боковой панелью;
  6. карточка «ContextFlow — AI for Safari».
- Подписи те же, что на скриншотах.

## Как пересобрать

Скрипты лежат в `~/ContextFlow-work/store-pages/shots26/`: `run.sh` для съёмки и сборки кадров, `rec.sh` для дублей видео. Тяжёлую работу запускать только под `.claude/heavy.lock`.

```bash
# кадры (обычный стенд и Pro-стенд с PREVIEW_PLAN=pro)
ONLY=iphone,ipad SCENES=watchpage,copied5done,selanswer,google PRO_SCENES=pdf STEP=capture ./run.sh
CF_ROOT=<repo> node compose.mjs <raw-en> <out-en> en ppo          # набор SETS_PPO
CF_ROOT=<repo> node creative.mjs <raw-en> <art-en> en             # header.png, search.png
# видео
LANGS="en ru" ./rec.sh                                            # дубли main, watch, copies, notes; fill на Pro-стенде; notes для Mac
SET=ppo CF_ROOT=<repo> node preview-render.mjs <rec-en> iphone.mp4 en iphone
```

На стенде появились страница с PDF-отчётом (`/report`, `/report-ru`, взята со стенда 2.4) и ответы для отчёта, для страницы товара и для вопроса к выделенному на русском (`answers.json`). Почтовая и магазинная страницы открываются на своих доменах через `--host-resolver-rules`.
