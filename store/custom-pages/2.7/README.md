# Кастомные страницы App Store 2.7

Шесть страниц продукта. Пять из них живут с 2.6, `cpp-arc` появилась в 2.7. Каждая получает новую версию в той же отправке, что и версия 2.7.

Имена страниц остались прежними («2.6 Shopping: …» и другие). Поэтому `job27.js` находит живые страницы и создаёт им новые версии, а ссылки `…?ppid=<id>` в рекламе и постах не меняются.

## Данные

`pages.json` хранит для каждой страницы:
- имя;
- аудиторию;
- промо-тексты en-US и ru (у `cpp-arc` только en-US);
- ключевые слова;
- порядок экранов.

Ключевые слова те же, что в 2.6: список ключевых слов приложения в 2.7 не менялся.

| `cpp-arc` (en) | ИИ на странице · пространства · главное · ответы из поиска · одни чаты · дешевле (Ultra) | добавлены пространства |

**Съёмка.** Всё снято на сборке 110:
- сцены 2.7: `tools/store/capture.mjs` с `SET=v27`;
- сцены 2.6 сняты заново: `SET=v26`;
- сборка экранов: `compose.mjs` с `SET=cpp27-<страница>`.

Экраны лежат вне репозитория, в `~/ContextFlow-work/store-pages/shots27/out-<en|ru>/cpp27-<страница>/<iphone|ipad>/`. Размеры: iPhone 1290×2796, iPad 2064×2752.

## Ревью

Страницы показывают функции 2.7, поэтому их новые версии подаются вместе с версией 2.7.
