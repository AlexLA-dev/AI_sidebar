# Apple Ads: первая кампания ContextFlow ($50)

`plan.json` — источник правды: кампании, группы, ключи, ставки, минус-слова и объявление (стандартная или своя страница продукта). `tools/ads/asa.mjs` приводит Apple Ads в соответствие с планом через Apple Ads Platform API v1 и предлагает правки по отчётам.

## Почему так (данные на 31.10.2026)

- Все 4 платные подписки пришли с **iPad**: 4 из ~22 загрузок на iPad за 20–30 октября. На iPhone (71 загрузка за месяц) и Mac (16) платных подписок пока нет.
- Страны подписчиков: США ×2, Германия, Франция. Трое купили Pro в течение 10–25 минут после установки, только один перед этим упёрся в лимит.
- Органика: поиск App Store даёт 64 загрузки в месяц, ChatGPT — 50. На iPad 70% просмотров страницы продукта из поиска заканчиваются загрузкой, на iPhone — 39%.
- Популярность запросов в США (1–5): «safari extension» 3, «summarize» / «tldr» / «ai browser» / «ai reader» 2, остальные нишевые 1. Трафик небольшой, поэтому ставки умеренные.
- Отраслевые ориентиры: CPT в США ~$1.5, в DE ~$0.86, в FR ~$0.75. Для freemium без пробного периода в платную подписку обычно переходит 2–3% установок.

## Панель

```
pnpm ads        # то же: node tools/ads/panel.mjs → http://localhost:8790
```

В панели:
- траты относительно $50, показы, тапы, установки, CPI;
- кампании, группы и ключи с метриками: ставку можно поменять, ключ или группу — поставить на паузу или включить, ключи — добавить;
- поисковые запросы с кнопками «+ exact» и «− минус»;
- минус-слова кампаний;
- предложения правил одним списком;
- кнопка «Пауза всего».

Изменения сначала собираются как черновик. По кнопке «Проверить и применить» панель показывает, что именно поменяется в Apple Ads. Защита бюджета ($50 и ставка до $1.50) не даст применить лишнее, а включение кампании требует отдельного подтверждения. Панель открывается только на этом Mac (localhost) и использует ключ из `~/.appleads`.

## Как пользоваться

Один раз:

1. Пригласить API-пользователя: Apple Ads → Account Settings → User Management → Invite Users, роль API Account Manager. Нужна другая почта, не та, под которой вы входите.
2. Выполнить `node tools/ads/asa.mjs keygen`. Публичный ключ вставить под этим пользователем в Account Settings → API.
3. clientId, teamId и keyId записать в `~/.appleads/config.json`, затем выполнить `node tools/ads/asa.mjs accounts` и вписать adAccountId.

Дальше:

```
node tools/ads/asa.mjs plan                 # что изменится (ничего не меняет)
node tools/ads/asa.mjs apply --yes          # создать или обновить; кампании остаются на паузе
# "status": "ENABLED" в plan.json, затем:
node tools/ads/asa.mjs apply --yes --launch # запуск
node tools/ads/asa.mjs report               # кампании, ключи, поисковые запросы
node tools/ads/asa.mjs optimize --write     # предложения правил → plan.json, затем plan / apply
node tools/ads/asa.mjs stop --yes           # всё на паузу
```

## Правила `optimize`

| Условие | Действие |
|---|---|
| 12 тапов или $4 без установок | ключ на паузу |
| TTR ниже 2.5% после 300 показов | ключ на паузу |
| CPI ≤ $1.50 или ключ привёл подписчика | ставка +15% (не выше $1.50) |
| CPI больше $3 | ставка −20% |
| Запрос из Discovery или broad дал установку | добавить exact-ключом |
| Запрос из Discovery или broad потратил $1.50 без установок | минус-слово |

Ключ, который привёл подписчика, на паузу не ставится. Подписчики по ключам берутся из Supabase (`cf_ads_funnel`), если в приложении есть атрибуция AdServices.
