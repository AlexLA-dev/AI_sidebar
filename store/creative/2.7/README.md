# Баннеры iOS 27 для 2.7

Header 21:9 (3840 × 1646) и баннер поиска 3:2 (3840 × 2560) для основной страницы и каждой кастомной: en-US и ru, у `cpp-arc` только en-US. Всё снято на сборке 110: `tools/store/creative27.mjs`. Сцены с ценами и адресами сняты отдельно с `BANNER=1`, адресная строка Safari нарисована пустой, как требует Apple.

## Что изменилось с 2.6.1

По плану `store-27-refresh-plan.md`:
- **Основная страница.** Баннер поиска теперь показывает перевод прямо на странице, а не «Найти похожее». Header остался прежним, с пересказом, но строка «Новое» под ним стала «Перевод страницы · Подборки · Пространства».
- **cpp-lang.** Header — перевод на странице.
- **cpp-study.** Header — подборки с таблицей «Сравнить».
- **cpp-work.** Header — «Проверить» с правками.

Остальные баннеры переделаны на 110 с теми же сценами, что в 2.6.1.

Все баннеры собраны на одном листе: `contact-sheet.jpg`.
