# ContextFlow — AI for every page in Safari

Safari Web Extension for iPhone, iPad and Mac (+ a Chrome build) that summarizes, explains and translates the page you're reading and answers questions about it. App Store: <https://apps.apple.com/app/id6759115793>.

## How it fits together

```
Safari page ──content script (shadow DOM UI)──► background worker ──► Netlify API ──► OpenAI
                                                      │                    │
                                     native messaging │                    └─► Supabase (schema "contextflow")
                                                      ▼
                                   SafariWebExtensionHandler.swift ◄── App Group ── ContextFlow app (StoreKit 2)
```

- **No accounts.** The extension creates a random install id. Free plan: `FREE_DAILY_LIMIT` answers per day (default 5), enforced on the server per install, per IP hash and with a global daily budget.
- **Subscriptions** (`com.contextflow.pro.monthly`, `com.contextflow.byok.monthly`) are bought in the app. The app (and the extension handler, live from StoreKit) share Apple's signed transaction (JWS); the backend verifies the signature chain up to Apple Root CA G3 and the App Store marker OIDs, and applies refunds/renewals from App Store Server Notifications.
- **Own OpenAI key** (Pro and "Own key" plans): requests go straight from the device to OpenAI.
- **Data**: page text is sent only when the user asks, never stored. Chats live in extension storage on the device.

## Repository

| Path | What |
|---|---|
| `src/background` | MV3 background worker: toolbar/shortcut toggle, chat streaming port, App Store status, native bridge |
| `src/content` | Panel UI (Preact, shadow DOM): side panel on Mac/iPad landscape, bottom sheet on iPhone, floating ✦ button, selection button |
| `src/locales` | UI strings (en, ru, uk, de, es, fr, it, pt_BR, ja, ko, zh_CN) → `_locales` at build time |
| `src/shared/prompt.ts` | System prompt shared by server and own-key mode |
| `netlify/functions` | `v2-chat` (`/api/v2/chat`), `v2-status` (`/api/v2/status`), `appstore-verify` (App Store notifications), `chat-proxy` (compat for builds ≤ 40), `stripe-webhook` (audit only) |
| `supabase/migrations` | Isolated `contextflow` schema + `cf_*` RPCs (service role only) |
| `ContextFlow/` | Xcode project (iOS + macOS app and extension). `Shared (Extension)/Resources` is generated by `pnpm run build` |
| `site/` | aisidebar.netlify.app: landing, privacy, terms (EULA), support |
| `store/` | App Store listing texts, screenshots, review notes, privacy answers |
| `tools/preview` | Local preview server (real handlers, fake model/DB) + Chromium end-to-end test |

## Develop

```bash
pnpm install
pnpm run typecheck && pnpm test      # backend + shared code
pnpm run build                       # Safari build → ContextFlow/Shared (Extension)/Resources (commit it)
pnpm run build:chrome                # Chrome build → build/chrome (load unpacked)

# Whole product locally (no OpenAI/Supabase needed):
node --experimental-strip-types tools/preview/server.mts          # http://localhost:8787/article
CF_API_BASE=http://localhost:8787 node scripts/build-extension.mjs --out=/tmp/cf-ext
node tools/preview/e2e.mjs /tmp/cf-ext /tmp/cf-e2e                # needs `playwright`
```

Open `ContextFlow/ContextFlow.xcodeproj` in Xcode 26+ to run the app/extension on a device or simulator.

## Release

1. Merge to `main` → Netlify deploys the API and site (aisidebar.netlify.app).
2. GitHub → Actions → **Release to App Store Connect** → Run workflow (needs secrets `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_PRIVATE_KEY` — an App Store Connect API key with Admin access). It archives iOS and macOS, signs with Xcode cloud signing and uploads the builds.
   Alternatively: Xcode → Product → Archive → Distribute App → App Store Connect.
3. In App Store Connect: attach the builds to version 2.0 and fill the listing from `store/` → Submit for Review.

## Backend operations

- Usage: run `select public.cf_stats(30);` in the Supabase SQL editor.
- Limits and model: Netlify environment variables (see `.env.example`), no redeploy of the app needed.
- App Store Server Notifications V2 URL: `https://aisidebar.netlify.app/.netlify/functions/appstore-verify` (production and sandbox).
