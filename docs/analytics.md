# Аналитика ContextFlow: где и что смотреть

| Вопрос | Где смотреть |
|---|---|
| Сколько людей видят страницу в сторе, скачивают, откуда приходят | App Store Connect → **Analytics** |
| Выручка, новые подписки, продления, отток | App Store Connect → **Sales and Trends** → Subscriptions; **Analytics → Subscriptions** |
| Пользуются ли расширением, что делают, где упираются в лимит | Supabase → **SQL editor** → представления `contextflow.v_*` (ниже) |
| Работает ли API, есть ли ошибки и задержки | Netlify → aisidebar → **Logs & Metrics → Observability** |
| Сколько стоит OpenAI | platform.openai.com → **Usage** (сверка с `est_cost_usd`) |

## Supabase: готовые отчёты

Supabase → проект → SQL editor → New query, например `select * from contextflow.v_summary;`. Удобно сохранить каждый запрос как snippet. Отчёты только читают данные и не доступны через публичный API.

| Отчёт | Что показывает |
|---|---|
| `contextflow.v_summary` | Итог за 7 и 30 дней: новые установки, активные, ответы, упоры в лимит, новые и активные подписки |
| `contextflow.v_daily` | По дням за 90 дней: установки, активные, ответы (всего / Pro / со старых сборок), упоры в лимит, среднее время ответа, токены, оценка затрат в $ |
| `contextflow.v_funnel_30d` | Воронка установок за 30 дней: открыли панель → получили ответ → вернулись в другой день → упёрлись в бесплатный лимит |
| `contextflow.v_actions_30d` | Какие кнопки нажимают: `summarize`, `key_points`, `explain`, `translate`, действия с выделенным текстом `sel_*` и свои вопросы (`question`) |
| `contextflow.v_audience` | Платформа × язык интерфейса: установки, активные за 7 дней, ответы |
| `contextflow.v_subscriptions` | Подписки по продуктам: активные, новые за 30 дней, возвраты, истёкшие |
| `contextflow.v_subscription_events` | События App Store по дням: подписка, продление, отмена автопродления, возврат |

Ключевые метрики для еженедельного обзора:
- **Активация** = `got_answer / opened_panel` в `v_funnel_30d`.
- **Возвращаемость** = `came_back / got_answer`.
- **Давление пейвола** = `hit_free_limit / got_answer`. Это доля тех, кому бесплатного лимита мало, — потенциальные покупатели Pro.
- **Себестоимость ответа** = `sum(est_cost_usd) / sum(answers)` в `v_daily`.

## Что не попадает в статистику

- Ответы в режиме «свой ключ OpenAI»: запросы идут с устройства напрямую в OpenAI, мимо нашего сервера.
- Показы пейвола и нажатия «Получить Pro» внутри расширения. Покупку видно (подписки), путь к ней — нет.
- Установка считается в момент, когда человек впервые открыл панель. Скачивания без включения расширения видны только в App Store Connect.

Личных данных нет: идентификатор установки случайный, IP хранится только как хэш с ежедневной солью, текст страниц не сохраняется.
