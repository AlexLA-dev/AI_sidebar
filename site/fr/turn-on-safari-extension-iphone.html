Activer une extension Safari sur iPhone et iPad

Mis à jour en novembre 2026 · par le développeur de ContextFlow

Vous avez installé une extension Safari et rien n’apparaît sur la page. Presque toujours, elle n’est pas encore autorisée sur les sites web. Les étapes sont les mêmes pour toutes les extensions ; je prends pour exemple ContextFlow, que je développe.

Sur iPhone

Ouvrez le menu de la page dans la barre d’adresse → ContextFlow → « Toujours autoriser… » → « Toujours autoriser sur chaque site web ».

Pas « Autoriser pendant un jour » : avec ce choix, ✦ disparaît dès demain.

Ou dans Réglages :

  1. Ouvrez l’app Réglages et accédez à Apps → Safari (pas ContextFlow) → Extensions → ContextFlow.
  2. Sous Autorisations, réglez « Tous les sites web » sur « Autoriser ». Si vous y voyez plutôt une liste de sites web, réglez chaque ligne sur « Autoriser ».
  3. De retour dans Safari, rechargez la page et touchez ✦.

Sur iPad

Touchez le bouton en forme de pièce de puzzle à côté de l’adresse → ContextFlow → « Toujours autoriser… » → « Toujours autoriser sur chaque site web ».

Pas « Autoriser pendant un jour » : avec ce choix, ✦ disparaît dès demain.

Ou dans Réglages :

  1. Ouvrez Réglages, puis Apps à gauche → Safari (pas ContextFlow) → Extensions → ContextFlow.
  2. Sous Autorisations, réglez « Tous les sites web » sur « Autoriser ». Si vous y voyez plutôt une liste de sites web, réglez chaque ligne sur « Autoriser ».
  3. De retour dans Safari, rechargez la page et touchez ✦.

Choisissez Safari dans la liste Apps, pas ContextFlow : ContextFlow y figure aussi, et sa propre page n’a pas d’interrupteur pour l’extension.

Activée, mais pas de bouton ?

  • « Tous les sites web » est encore sur « Demander ». Réglez-le sur « Autoriser » dans Réglages, comme ci-dessus, et rechargez la page.
  • Navigation privée. Les extensions n’y fonctionnent que si vous l’autorisez : Réglages › Apps › Safari › Extensions › ContextFlow › « Autoriser en navigation privée ».
  • Une page où les extensions ne fonctionnent pas. Safari tient les extensions à l’écart de sa page de démarrage, des pages de l’App Store et de quelques autres. Ouvrez un site web classique.

Sur Mac

  • Safari › Réglages › Extensions, cochez ContextFlow et autorisez-le sur tous les sites web.
  • Cliquez ensuite sur ContextFlow dans la barre d’outils, ou appuyez sur Control-Shift-E.

Est-il sûr de l’autoriser sur tous les sites web ?

Safari affiche le même avertissement pour toutes les extensions, car il ne peut pas savoir ce que fait chacune. ContextFlow ne lit une page que lorsque vous lui demandez quelque chose, et le texte de la page n’est pas conservé sur mon serveur. Vous pouvez aussi l’autoriser site par site ; ✦ n’apparaît alors que sur ces sites.

Questions

Où sont les extensions de Safari ?

Leurs réglages se trouvent dans l’app Réglages : Apps → Safari → Extensions. Dans Safari même, elles sont dans le menu de la page de la barre d’adresse sur iPhone, et derrière le bouton en forme de pièce de puzzle à côté de l’adresse sur iPad.

Faut-il d’abord ouvrir l’app ?

Non : l’extension s’active dans Réglages. Si vous avez un abonnement, ouvrez une fois l’app ContextFlow pour qu’il parvienne à l’extension.

Je l’ai activée et je ne vois toujours rien.

Ouvrez Réglages → Apps → Safari → Extensions → ContextFlow, vérifiez que « Tous les sites web » est réglé sur « Autoriser », puis rechargez la page.

Est-ce que ça marche sur iPad ?

Oui. Les étapes dans Réglages sont les mêmes ; sur iPad, Apps se trouve dans la liste de gauche.
