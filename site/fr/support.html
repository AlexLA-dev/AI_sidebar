Assistance

Écrivez à top10resource@gmail.com — nous répondons généralement sous un jour ouvré.

Premiers pas

Comment activer ContextFlow sur iPhone ou iPad ?

Ouvrez l’app Réglages → Apps → Safari → Extensions → ContextFlow, activez-le et réglez Tous les sites web sur Autoriser. Ouvrez ensuite n’importe quel site dans Safari et touchez le bouton ✦ (ou le menu de la page dans la barre d’adresse → ContextFlow).

Comment l’activer sur Mac ?

Ouvrez Safari → Réglages → Extensions et cochez ContextFlow, puis autorisez-le sur tous les sites web. Cliquez sur l’icône ContextFlow dans la barre d’outils ou appuyez sur Control-Shift-E sur n’importe quelle page.

Rien ne se passe quand je touche le bouton

Vérifiez que ContextFlow est autorisé sur le site (menu de la page de Safari → ContextFlow → Toujours autoriser sur tous les sites web). Certaines pages ne peuvent pas être lues par les extensions (la page de démarrage de Safari, les pages de l’App Store) ; ouvrez plutôt un site classique. Recharger la page après avoir activé l’extension aide aussi.

Forfaits et abonnements

Combien de réponses gratuites ai-je ?

5 réponses par jour, renouvelées à minuit UTC. Aucun compte n’est nécessaire.

J’ai pris un abonnement, mais ContextFlow affiche toujours le forfait Gratuit

Ouvrez une fois l’app ContextFlow (elle transmet votre abonnement à l’extension), puis rouvrez le panneau dans Safari. Si nécessaire, touchez Restaurer les achats sur l’écran Pro.

Un abonnement fonctionne-t-il sur tous mes appareils ?

Oui — sur chaque iPhone, iPad et Mac connecté au même compte Apple. Ouvrez une fois l’app ContextFlow sur chaque appareil.

Comment résilier ?

iPhone/iPad : Réglages → votre nom → Abonnements → ContextFlow. Mac : App Store → votre nom → Réglages du compte → Abonnements. Vous gardez l’accès jusqu’à la fin de la période payée.

Comment utiliser ma propre clé OpenAI ou Claude ?

Avec le forfait Pro ou Clé personnelle, ouvrez le panneau ContextFlow dans Safari → Réglages → Clé d’API personnelle et collez une clé OpenAI (sk-…) ou Anthropic (sk-ant-…). Sous Modèle, choisissez Rapide (le dernier Claude Haiku ou GPT mini) ou Intelligent (le dernier Claude Sonnet ou GPT). Les requêtes vont alors directement de votre appareil à ce fournisseur.

Confidentialité

Qu’est-ce qui est envoyé quand je pose une question ?

Votre question et le texte de la page (ou votre sélection) — uniquement à ce moment-là, uniquement pour générer la réponse. Les détails sont dans la Politique de confidentialité.

J’avais un compte dans une ancienne version. Comment le supprimer ?

Écrivez-nous depuis l’adresse utilisée lors de l’inscription, et nous le supprimerons sous 30 jours. La version 2.0 n’utilise plus de comptes.
