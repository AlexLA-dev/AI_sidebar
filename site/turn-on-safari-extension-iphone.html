Turn on a Safari extension on iPhone and iPad

Updated November 2026 · from the developer of ContextFlow

You installed a Safari extension and nothing shows on the page. Almost always Safari needs one more answer from you. The steps are the same for any extension; I use ContextFlow, which I make, as the example.

Right in Safari

  1. Open any website and tap the page menu button in the address bar.
  2. Tap Manage Extensions and switch ContextFlow on.
  3. Back in the page menu, tap ContextFlow, then choose Always Allow, then Always Allow on Every Website.

In Settings

  1. Open the Settings app, then Apps › Safari › Extensions › ContextFlow.
  2. Switch it on and set All Websites to Allow.
  3. Go back to Safari and reload the page.

Turned on, but no button?

  • Safari is still asking. With All Websites left on Ask, the button doesn't appear, and Safari's question waits in the page menu: ContextFlow is marked ⚠ there. Tap it and choose Always Allow, then Always Allow on Every Website.
  • The extension is off. It isn't in the page menu at all: tap Manage Extensions there and switch it on.
  • Private Browsing. Extensions run there only if you allow it: Settings › Apps › Safari › Extensions › ContextFlow › Allow in Private Browsing.
  • A page extensions can't run on. Safari keeps extensions off its start page, App Store pages and a few others. Open a regular website.

On Mac

  • Safari › Settings › Extensions, tick ContextFlow and allow it on every website.
  • Then click ContextFlow in the toolbar, or press Control-Shift-E.

Is Always Allow on Every Website safe?

Safari shows the same warning for every extension, because it can't know what one does. ContextFlow reads a page only when you ask it something, and page text isn't kept on my server. You can also allow it site by site instead; then ✦ shows only on those sites.

Questions

Where is the page menu?

It's the button in Safari's address bar that opens the page's options, like Reader, Translate and your extensions. How it looks depends on your iOS version.

Do I need to open the app first?

Turning the extension on works from Safari or Settings. Open the ContextFlow app once if you have a subscription, so it reaches the extension.

I turned it on and still see nothing.

Reload the page. If ✦ still doesn't show, open the page menu: if ContextFlow is marked ⚠ there, Safari is still asking for your permission.

Does it work on iPad?

Yes, the steps are the same as on iPhone.
