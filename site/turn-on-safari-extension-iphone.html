Turn on a Safari extension on iPhone and iPad

Updated November 2026 · from the developer of ContextFlow

You installed a Safari extension and nothing shows on the page. Almost always it isn't allowed on websites yet. The steps are the same for any extension; I use ContextFlow, which I make, as the example.

On iPhone

Open the page menu in the address bar → ContextFlow → “Always Allow…” → “Always Allow on Every Website”.

Not “Allow for One Day”: with it, ✦ is gone again tomorrow.

Or in Settings:

  1. Open Settings and go to Apps → Safari (not ContextFlow) → Extensions → ContextFlow.
  2. Under Permissions, set All Websites to Allow. If you see a list of websites there instead, set every row in it to Allow.
  3. Back in Safari, reload the page and tap ✦.

On iPad

Tap the puzzle-piece button next to the address → ContextFlow → “Always Allow…” → “Always Allow on Every Website”.

Not “Allow for One Day”: with it, ✦ is gone again tomorrow.

Or in Settings:

  1. Open Settings, then Apps on the left → Safari (not ContextFlow) → Extensions → ContextFlow.
  2. Under Permissions, set All Websites to Allow. If you see a list of websites there instead, set every row in it to Allow.
  3. Back in Safari, reload the page and tap ✦.

Turned on, but no button?

  • All Websites is still on Ask. Set it to Allow in Settings, as above, and reload the page.
  • Private Browsing. Extensions run there only if you allow it: Settings › Apps › Safari › Extensions › ContextFlow › Allow in Private Browsing.
  • A page extensions can't run on. Safari keeps extensions off its start page, App Store pages and a few others. Open a regular website.

On Mac

  • Safari › Settings › Extensions, tick ContextFlow and allow it on every website.
  • Then click ContextFlow in the toolbar, or press Control-Shift-E.

Is allowing it on every website safe?

Safari shows the same warning for every extension, because it can't know what one does. Page text is sent only when you ask something and is not used to train models. You can also allow it site by site instead; then ✦ shows only on those sites.

Questions

Where are Safari's extensions?

Their settings are in the Settings app: Apps → Safari → Extensions. In Safari itself, they're in the page menu in the address bar on iPhone, and behind the puzzle-piece button next to the address on iPad.

Do I need to open the app first?

No: the extension is turned on in Settings. Open the ContextFlow app once if you have a subscription, so it reaches the extension.

I turned it on and still see nothing.

Open Settings → Apps → Safari → Extensions → ContextFlow and check that All Websites is set to Allow, then reload the page.

Does it work on iPad?

Yes. The steps in Settings are the same; on iPad, Apps is in the list on the left.
