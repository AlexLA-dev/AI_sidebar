入门

如何在 iPhone 或 iPad 上启用 ContextFlow？

打开“设置”App →“App”→“Safari”→“扩展”→ ContextFlow，打开开关，并将所有网站设为允许。然后在 Safari 中打开任意网站并轻点 ✦ 按钮（或地址栏中的页面菜单 → ContextFlow）。

如何在 Mac 上启用？

打开 Safari →“设置”→“扩展”并勾选 ContextFlow，然后允许它在所有网站上运行。在任意网页上点按工具栏中的 ContextFlow 图标，或按下 Control-Shift-E。

轻点按钮后没有反应

请确认已允许 ContextFlow 在该网站上运行（Safari 的页面菜单 → ContextFlow →“在所有网站上始终允许”）。有些页面无法被扩展读取（Safari 的起始页、App Store 页面）；请改为打开普通网站。启用扩展后重新载入页面也会有帮助。

套餐与订阅

我有多少次免费回答？

每天 5 次回答，在 UTC 午夜重置。无需账户。

我已订阅，但 ContextFlow 仍显示免费版

打开一次 ContextFlow App（它会把你的订阅共享给扩展），然后在 Safari 中重新打开面板。如有需要，在套餐页面轻点恢复购买。

一份订阅能在我的所有设备上使用吗？

能。适用于登录同一 Apple 账户的所有 iPhone、iPad 和 Mac。在每台设备上打开一次 ContextFlow App 即可。

怎么改为年付，或升级到 Ultra？

在 ContextFlow App 中，打开“设置”→“你的套餐”。从月付改为年付，会在你当前这个月结束时开始。从 Pro 升级到 Ultra 立即生效，Apple 会退还 Pro 剩余的部分。

如何取消订阅？

iPhone/iPad：设置 → 你的姓名 → 订阅 → ContextFlow。Mac：App Store → 你的姓名 → 账户设置 → 订阅。在已付费的周期结束前，你仍可继续使用。

如何使用自己的 OpenAI 或 Claude 密钥？

使用 Pro、Ultra 或“自有密钥”套餐时，在 Safari 中打开 ContextFlow 面板 →“设置”→“自有 API 密钥”，粘贴 OpenAI 密钥（sk-…）或 Anthropic 密钥（sk-ant-…）。在“模型”下选择“快速”（最新的 Claude Haiku 或 GPT mini）或“智能”（最新的 Claude Sonnet 或 GPT）。之后请求将直接从你的设备发送到该服务商。

隐私

提问时会发送什么？

你的问题和网页文本（或你选中的内容），只在那一刻发送，只用于生成回答。详情见隐私政策。

我在旧版本中注册过账户，如何删除？

用你注册时使用的邮箱给我们发邮件，我们会在 30 天内删除。2.0 版起不再使用账户。
