ContextFlow, Zeki, SurfMind: 페이지 옆에 두는 AI 사이드바 세 가지

2026년 11월 업데이트 · ContextFlow 개발자가 씀

셋 다 읽고 있는 페이지 옆에 AI 채팅을 두고, 셋 다 페이지 요약과 선택한 텍스트 작업을 할 수 있어요. ContextFlow와 Zeki는 Safari에서 작동해요. SurfMind의 App Store 페이지에는 “사용 중인 브라우저”라고 적혀 있고, 어떤 브라우저인지는 나오지 않아요. 차이는 그 위에 더해지는 기능에 있어요. 저는 ContextFlow를 만드는 사람이라 중립적이지 않아요. Zeki와 SurfMind는 2026년 11월 기준 App Store 페이지에 적힌 그대로 소개해요.

Zeki

  • iPhone, iPad, Mac의 Safari 사이드바와 채팅 앱.
  • 내 키: 무료, 무제한. Anthropic, OpenAI, Google, OpenRouter, Groq, Mistral의 키와 그 키로 쓸 수 있는 모든 모델을 쓸 수 있어요.
  • 키 없이: 주당 무료 메시지 30개, 또는 Apple로 로그인한 뒤 Zeki Plus나 Pro 구독(하루 메시지 200개 또는 1,000개).
  • 두 모델을 나란히 비교하고, 파일·PDF·이미지를 읽고, 웹을 검색하고, 지식 베이스를 보관해요.
  • 이럴 때 고르세요: 모델을 직접 고르고 싶고 이미 API 키가 있을 때.

SurfMind

  • App Store 페이지에는 iPhone과 Mac이 나와 있어요.
  • 내 키로 쓰는 100+ 모델, 시작용 체험 크레딧, Ollama, LM Studio 등을 통한 로컬 모델.
  • 열려 있는 여러 탭의 정보를 비교하고, 페이지에서 클릭, 스크롤, 입력을 해 대신 작업을 해 줘요.
  • 이럴 때 고르세요: 로컬 모델, 여러 탭 동시 사용, 페이지에서 직접 작업하는 어시스턴트를 원할 때.

ContextFlow

  • iPhone, iPad, Mac의 Safari. 계정 없이 켜는 즉시 작동해요.
  • 키 없이: 무료로 하루 답변 5개, Pro나 Ultra는 더 많이. 답변은 Anthropic의 Claude가 만들고, Claude를 쓸 수 없을 때는 OpenAI가 만들어요. 모델은 고를 수 없어요.
  • 내 키: ‘내 키’ 요금제에서 OpenAI 또는 Claude 키로.
  • 채팅 말고도:
    • 페이지 전체를 그 자리에서 번역하고, 링크도 그대로 작동해요.
    • 웹 사이트에서 입력하는 글을 페이지 내용을 고려해 검사하고 다시 써요.
    • ‘듣기’로 답변과 페이지 전체를 소리 내어 읽어 줘요(Ultra).
    • ‘비슷한 것 찾기’로 더 싸거나, 재고가 있거나, 더 새로운 대안을 찾고 페이지마다 확인해요(Pro, ‘내 키’, Ultra).
    • ‘가격 지켜보기’로 페이지의 가격이 바뀌면 알려 줘요.
    • 메모, 채팅, 컬렉션이 관련된 페이지와 함께 남아요.
  • 이럴 때 고르세요: 계정이나 키를 원하지 않고, 여러 모델로 조사하기보다 Safari에서 읽고, 쇼핑하고, 글을 쓰는 일이 더 많을 때.
  • 웹 사이트 차단이나 집중 모드는 없어요. 같은 이름의 Chrome 확장 프로그램에는 있지만, 그건 다른 앱이에요.

자주 묻는 질문

어느 것이 가장 좋나요?

하는 일에 따라 달라요. API 키가 있고 모델을 고르고 싶다면 Zeki. 로컬 모델과 페이지에서 직접 작업하는 어시스턴트를 원한다면 SurfMind. 계정도 키도 없이, 번역, 검사, ‘듣기’, ‘비슷한 것 찾기’를 Safari 안에서 바로 쓰고 싶다면 ContextFlow예요.

ContextFlow는 무료인가요?

네, 무료로 시작할 수 있어요. 하루 답변 5개, 계정 필요 없음. Pro와 Ultra는 답변도 기능도 더 많아요. ‘내 키’ 요금제는 내 OpenAI 또는 Claude 키를 써요.

ContextFlow가 Chrome용 웹 사이트 차단 앱인가요?

아니요. 그건 이름이 비슷한 다른 앱이에요. 이 ContextFlow는 App Store의 “ContextFlow: AI for Safari”이고, iPhone, iPad, Mac용이에요.

셋 다 써 볼 수 있나요?

네. 셋 다 App Store에서 무료로 시작할 수 있어요.
