시작하기

iPhone이나 iPad에서 ContextFlow를 어떻게 켜나요?

설정 앱 → 앱 → Safari → 확장 프로그램 → ContextFlow를 열고, 켠 다음 모든 웹 사이트를 허용으로 설정하세요. 그런 다음 Safari에서 아무 웹 사이트나 열고 ✦ 버튼을 탭하세요(또는 주소 막대의 페이지 메뉴 → ContextFlow).

Mac에서는 어떻게 켜나요?

Safari → 설정 → 확장 프로그램을 열고 ContextFlow를 체크한 다음, 모든 웹 사이트에서 허용하세요. 어느 페이지에서든 도구 막대의 ContextFlow 아이콘을 클릭하거나 Control-Shift-E를 누르세요.

버튼을 탭해도 아무 반응이 없어요

사이트에서 ContextFlow가 허용되어 있는지 확인하세요(Safari의 페이지 메뉴 → ContextFlow → 모든 웹 사이트에서 항상 허용). 일부 페이지는 확장 프로그램이 읽을 수 없어요(Safari의 시작 페이지, App Store 페이지). 대신 일반 웹 사이트를 여세요. 확장 프로그램을 켠 뒤 페이지를 새로 고침하는 것도 도움이 돼요.

요금제와 구독

무료 답변은 몇 개인가요?

매일 답변 5개이며, UTC 자정에 갱신돼요. 계정이 필요 없어요.

구독했는데 ContextFlow에 여전히 무료 플랜이 표시돼요

ContextFlow 앱을 한 번 여세요(앱이 확장 프로그램과 구독을 공유해요). 그런 다음 Safari에서 패널을 다시 여세요. 필요하면 요금제 화면에서 구입 항목 복원을 탭하세요.

구독 하나로 모든 기기에서 쓸 수 있나요?

네. 같은 Apple 계정으로 로그인한 모든 iPhone, iPad, Mac에서요. 기기마다 ContextFlow 앱을 한 번 여세요.

연간으로 바꾸거나 Ultra로 업그레이드하려면 어떻게 하나요?

ContextFlow 앱에서 ‘설정’ → ‘내 요금제’를 여세요. 월간에서 연간으로 바꾸면 지금 한 달이 끝날 때 시작돼요. Pro에서 Ultra로 바꾸면 바로 시작되고, Pro의 남은 기간은 Apple이 환불해요.

어떻게 취소하나요?

iPhone/iPad: 설정 → 사용자 이름 → 구독 → ContextFlow. Mac: App Store → 사용자 이름 → 계정 설정 → 구독. 결제한 기간이 끝날 때까지 계속 이용할 수 있어요.

내 OpenAI 또는 Claude 키는 어떻게 쓰나요?

Pro, Ultra 또는 ‘내 키’ 요금제에서 Safari의 ContextFlow 패널 → 설정 → 내 API 키를 열고 OpenAI 키(sk-…)나 Anthropic 키(sk-ant-…)를 붙여 넣으세요. ‘모델’에서 ‘빠름’(최신 Claude Haiku 또는 GPT mini)이나 ‘똑똑함’(최신 Claude Sonnet 또는 GPT)을 고르세요. 그러면 요청이 기기에서 해당 제공업체로 바로 전송돼요.

개인정보 보호

질문하면 무엇이 전송되나요?

질문과 페이지 텍스트(또는 선택한 부분)가 그 순간에만, 답변을 만드는 데에만 전송돼요. 자세한 내용은 개인정보 처리방침에 있어요.
