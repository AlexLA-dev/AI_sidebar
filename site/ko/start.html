아래에 짧은 글이 있어요. 이 글에 대해 ContextFlow에 물어보세요. 그것만으로 어떻게 작동하는지 알 수 있어요.

  1. 이 페이지에서 ContextFlow가 켜져 있어요찾는 중…찾았어요. ✦는 화면 가장자리에 있어요.아직이에요. 바로 아래에서 켜는 방법을 확인하세요.

  2. ✦ 탭하기화면 가장자리에 있는 둥근 버튼이에요. 옮기지 않았다면 오른쪽에 있어요.

  3. 아래 글에 대해 물어보기‘요약’을 탭하거나 직접 질문을 입력하세요.

페이지에 ✦가 없나요? ContextFlow가 아직 웹 사이트에서 허용되지 않았어요.

주소 막대의 페이지 메뉴 → ContextFlow → '항상 허용…' → '모든 웹사이트에서 항상 허용' 순서로 탭하세요.

'1일 동안 허용'은 고르지 마세요. 내일이면 ✦가 다시 사라져요.

또는 설정에서:

  1. 설정 앱을 열고 앱 → Safari(ContextFlow 아님) → 확장 프로그램 → ContextFlow로 이동하세요.
  2. 권한에서 '모든 웹 사이트'를 '허용'으로 설정하세요. 대신 웹 사이트 목록이 보이면 목록의 모든 항목을 '허용'으로 설정하세요.
  3. Safari로 돌아가 페이지를 새로고침하고 ✦를 탭하세요.

주소 옆의 퍼즐 조각 버튼 → ContextFlow → '항상 허용…' → '모든 웹사이트에서 항상 허용' 순서로 탭하세요.

'1일 동안 허용'은 고르지 마세요. 내일이면 ✦가 다시 사라져요.

또는 설정에서:

  1. 설정을 열고 왼쪽의 앱 → Safari(ContextFlow 아님) → 확장 프로그램 → ContextFlow로 이동하세요.
  2. 권한에서 '모든 웹 사이트'를 '허용'으로 설정하세요. 대신 웹 사이트 목록이 보이면 목록의 모든 항목을 '허용'으로 설정하세요.
  3. Safari로 돌아가 페이지를 새로고침하고 ✦를 탭하세요.

Safari에서 ContextFlow를 켜세요. Safari › 설정 › 확장 프로그램에서 ContextFlow를 체크하고 모든 웹 사이트에서 허용하세요. 그런 다음 도구 막대에서 ContextFlow를 클릭하세요.

Safari가 이 웹 사이트에 대해 물으면

‘항상 허용’을 선택하세요. 페이지 텍스트는 질문할 때만 전송되며 모델 학습에 사용되지 않아요.

이 글로 해 보세요

우리는 왜 읽은 것을 대부분 잊어버릴까요

1880년대에 독일 심리학자 헤르만 에빙하우스는 “WID”, “ZOF” 같은 무의미한 음절 목록을 몇 달 동안 외우고, 나중에 스스로 시험해 봤어요. 그가 알아낸 건 망각이 처음에 가장 빠르다는 사실이었어요. 목록의 상당 부분이 첫 한 시간 안에 사라졌고, 다음 날까지 더 많이 사라졌어요. 그 뒤로는 잊는 속도가 느려졌어요.

그의 곡선에는 한계가 있어요. 무의미한 음절은 아무 뜻도 없지만, 우리에게 중요한 것이나 이미 아는 것과 연결되는 것은 기억하기가 더 쉬워요. 그래도 곡선의 모양은 그대로예요. 다시 보지 않으면 긴 글의 대부분은 며칠 안에 흐려져요.

도움이 되는 습관이 두 가지 있어요. 하루 뒤, 그리고 일주일 뒤처럼 시간을 두고 다시 보면 연달아 두 번 읽을 때보다 더 많이 남아요. 그리고 생각을 내 말로 바꿔 말해 보면, 단 한 문장이라도 다시 읽는 것보다 기억에 더 잘 남아요.

  • “그의 곡선에는 한계가 있어요”를 선택하고 “정말 그래요?”라고 물어보세요.
  • “이후 연구에서는 이에 대해 무엇을 알아냈나요?”
