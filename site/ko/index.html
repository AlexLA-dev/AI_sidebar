변경 알림과 리마인더

듣기 Ultra

답변 아래의 ‘듣기’를 탭하거나 ‘이 페이지 듣기’를 고르세요. 자연스러운 목소리가 100개 이상의 언어로, 1×, 1.2×, 1.5×, 2× 속도로 읽어 줘요. iPhone에서는 화면을 잠가도 계속 재생돼요.

비슷한 것 찾기 Ultra

어떤 페이지든, 선택한 부분이든 대안을 찾아 줘요. 더 저렴하게, 더 최신, 재고 있음, 무료, 내 언어로 중에서 고르거나 원하는 것을 직접 적어도 돼요. 모든 링크는 보여 드리기 전에 열어서 확인해요.

50개 페이지 지켜보기 Ultra

사용 방법

App Store에서 ContextFlow를 설치하고 Safari에서 켜세요(iPhone에서는 설정 → 앱 → Safari → 확장 프로그램, Mac에서는 Safari → 설정 → 확장 프로그램).
아무 웹 사이트나 열고 ✦를 탭하세요. 또는 도구 막대의 ContextFlow 아이콘을 클릭하세요(Mac에서는 Control-Shift-E).
요약, 핵심 정리, 쉽게 설명, 번역 중에서 고르거나 직접 질문하세요.

iPhone Safari의 AI

AI 확장 프로그램이 읽고 있는 페이지로 무엇을 할 수 있는지, 그리고 켜는 방법.

읽으면서 메모하기

Safari를 떠나지 않고, 메모를 그 메모가 나온 페이지 옆에 남겨 두세요.

Safari 요약일까, ChatGPT일까?

Safari 자체 요약, ChatGPT에 붙여 넣기, ContextFlow를 솔직하게 비교했어요.

자주 묻는 질문

계정이 필요한가요?

아니요. ContextFlow는 Safari에서 켜는 즉시 작동해요. 구독은 Apple 계정에 연결되어 모든 기기에서 쓸 수 있어요.

ContextFlow는 어떤 AI를 쓰나요?

답변은 Anthropic의 Claude가 만들고, Claude를 쓸 수 없을 때는 OpenAI가 만들어요. Google 답변은 Gemini를 통해 Google 검색을 쓰고, 듣기는 Google의 Gemini 음성을 써요. ‘내 키’ 요금제에서는 내 OpenAI 또는 Claude 키를 써요. 페이지 텍스트는 질문할 때만 전송되며 모델 학습에 사용되지 않아요.

2.6에서 무엇이 새로워졌나요?

‘듣기’와 ‘비슷한 것 찾기’가 있는 Ultra, 연간 요금제, 채팅 맨 위의 추천 막대로 주제별로 정리되는 채팅(Pro), 리마인더와 지켜보기에 남기는 내 메모, 선택한 텍스트 바로 아래의 빠른 동작, 그리고 중국어 번체, 아랍어, 베트남어 패널이에요. 업데이트하고 나면 ContextFlow 앱이 주요 변경 사항을 짧은 영상으로 보여 줘요.

Ultra에는 Pro보다 무엇이 더 있나요?

답변과 페이지 전체를 소리 내어 읽어 주는 ‘듣기’(주당 30분), 어떤 페이지든 확인된 대안을 찾아 주는 ‘비슷한 것 찾기’(주당 10회), 그리고 20개가 아닌 최대 50개 페이지 지켜보기예요. Pro에서 바꾸면 바로 시작되고, Pro의 남은 기간은 Apple이 환불해요.

모든 웹 사이트에서 작동하나요?

일반 웹 사이트에서는 네. Safari는 일부 페이지(시작 페이지, App Store 페이지, 경우에 따라 PDF)를 확장 프로그램이 읽지 못하게 해요. 그런 곳에서도 일반적인 질문은 할 수 있어요.
