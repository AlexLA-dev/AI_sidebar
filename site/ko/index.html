시작하기

어떤 페이지에서든 열어 보세요. 탭 한 번으로 요약하고, 한 문단만 골라 묻고, Google에서 최신 정보를 받아요. 채팅은 페이지에서 페이지로 따라오고, 새 페이지에서는 그 주제의 채팅이 알아서 열려요.

더 깊이 파고들기

페이지 옆에 남기는 내 메모(원하면 페이지 스냅샷도 함께), 답변의 하이라이트와 고정, 채팅 전체를 반영한 답변. 동영상, PDF, ‘비슷한 것 찾기’ 빠른 버전 Pro ‘듣기’와 ‘비슷한 것 찾기’ 풀 버전 Ultra

빠른 삽입

다른 탭에서 복사하거나 잘라 낸 텍스트, 템플릿, 마지막 답변을 어떤 텍스트 필드에서든 탭 한 번으로 넣어요. 템플릿은 이름과 날짜를 페이지에서 채우고, ‘검사’는 보내기 전에 초안을 고쳐 줘요.

변경 알림과 리마인더

어떤 텍스트든 선택하거나 페이지 전체를 고르고, 원하면 나에게 남기는 메모도 더하세요. 종은 고른 시간에 페이지로 다시 데려다주고, 눈은 가격이 내리거나 재입고되면 알려 줘요. 리마인더는 Apple 미리 알림으로, 날짜는 캘린더로 보낼 수도 있어요.

채팅 정리

업무용과 개인용 스페이스, 검색, 태그, 폴더, 앱과 모든 기기에서 보는 모든 채팅. AI 검색, 모든 채팅에 대한 질문, 그리고 메시지를 어울리는 채팅으로 옮기고 채팅을 합치고 주제로 이름을 지어 주는 추천 Pro

개인정보 및 맞춤 설정

계정도 추적도 없어요. 채팅은 내 기기와 iCloud에 남고, 페이지 텍스트는 제 서버에 절대 저장되지 않아요.

2.7의 새 기능

그 자리에서 번역되는 페이지, 쓰는 글에 대한 도움, 그리고 생활의 영역마다 하나씩 두는 스페이스.

페이지를 그 자리에서 번역

다른 언어로 된 페이지인가요? ✦ 옆의 ‘번역’을 탭하면 레이아웃은 그대로 둔 채 내 언어로 읽을 수 있어요. 링크도 그대로 작동하고, ‘원문’을 누르면 모든 글이 원래대로 돌아와요.

검사와 다시 쓰기

이메일 답장이나 댓글에서 ‘검사’는 오류를 고치고, ‘다시 쓰기’는 글을 ‘더 짧게’, ‘더 따뜻하게’, ‘더 격식 있게’ 바꿔 줘요. 둘 다 페이지를 읽기 때문에 이름은 페이지에 적힌 그대로 나와요. Pro에서는 입력하는 동안 오류에 밑줄이 그어져요.

스페이스

업무, 개인, 쇼핑: 스페이스마다 자기 채팅과 색상이 있고, 어떤 사이트는 늘 정해 둔 스페이스에서 열리게 할 수도 있어요.

캘린더 및 미리 알림

“금요일에 호텔 예약하라고 알려 줘”라고 하거나, 답변에서 날짜를 가져오세요. 카드에 날짜와 시간이 나오고, ‘추가’를 누르면 Apple 미리 알림이나 캘린더에 들어가요.

메모에 스냅샷

메모에 내가 본 그대로의 페이지 이미지를 남길 수 있어요. 화면에 보이는 부분, 또는 Pro에서는 페이지 전체를요. 원하면 잘라 낼 수도 있어요.

Pro에서도 ‘비슷한 것 찾기’ Pro

Pro와 ‘내 키’ 요금제에서 대안을 찾는 빠른 검색을 주당 5회까지 쓸 수 있어요. Ultra는 지금처럼 풀 버전 검색을 써요.

컬렉션

여행이나 구매처럼, 채팅의 답변과 메모를 컬렉션 하나에 모으세요. Pro에서는 표로 비교할 수 있어요. 컬렉션 전체는 PDF로 저장할 수 있어요.

친구 초대

친구에게 내 코드를 보내세요. 친구는 첫 주 동안 보너스 답변을 받고, 친구가 서로 다른 이틀에 사용하면 나는 Pro나 Ultra 할인을 받아요.

Ultra

Pro의 모든 기능에, 듣고 싶은 것을 읽어 주는 목소리와 지금 보고 있는 것의 대안이 더해져요.

듣기 Ultra

답변 아래의 ‘듣기’를 탭하거나 ‘이 페이지 듣기’를 고르세요. 자연스러운 목소리가 100개 이상의 언어로, 1×, 1.2×, 1.5×, 2× 속도로 읽어 줘요. iPhone에서는 화면을 잠가도 계속 재생돼요.

비슷한 것 찾기 Ultra

어떤 페이지든, 선택한 부분이든 대안을 찾아 줘요. 더 저렴하게, 더 최신, 재고 있음, 무료, 내 언어로 중에서 고르거나 원하는 것을 직접 적어도 돼요. 모든 링크는 보여 드리기 전에 열어서 확인해요. Pro에서는 빠른 버전을 주당 5회까지 쓸 수 있어요.

50개 페이지 지켜보기 Ultra

최대 50개 페이지의 가격, 재고, 변화를 한 번에 지켜봐요. Pro는 20개, 무료 플랜은 5개예요.

사용 방법

App Store에서 ContextFlow를 설치하고 Safari에서 켜세요(iPhone에서는 설정 → 앱 → Safari → 확장 프로그램, Mac에서는 Safari → 설정 → 확장 프로그램).
아무 웹 사이트나 열고 ✦를 탭하세요. 또는 도구 막대의 ContextFlow 아이콘을 클릭하세요(Mac에서는 Control-Shift-E).
요약, 핵심 정리, 쉽게 설명, 번역 중에서 고르거나 직접 질문하세요.

iPhone Safari의 AI

AI 확장 프로그램이 읽고 있는 페이지로 무엇을 할 수 있는지, 그리고 켜는 방법.

읽으면서 메모하기

Safari를 떠나지 않고, 메모를 그 메모가 나온 페이지 옆에 남겨 두세요.

Safari 요약일까, ChatGPT일까?

Safari 자체 요약, ChatGPT에 붙여 넣기, ContextFlow를 솔직하게 비교했어요.

Safari에서 페이지 번역하기

Safari 자체 번역, 그리고 링크가 그대로 작동하는 페이지 내 번역.

Safari에서 쓴 글 검사하기

Apple의 글쓰기 도구, Grammarly, 그리고 답하는 페이지를 읽고 하는 검사.

자주 묻는 질문

계정이 필요한가요?

아니요. ContextFlow는 Safari에서 켜는 즉시 작동해요. 구독은 Apple 계정에 연결되어 모든 기기에서 쓸 수 있어요.

ContextFlow는 어떤 AI를 쓰나요?

답변은 Anthropic의 Claude가 만들고, Claude를 쓸 수 없을 때는 OpenAI가 만들어요. Google 답변은 Gemini를 통해 Google 검색을 쓰고, 듣기는 Google의 Gemini 음성을 써요. ‘내 키’ 요금제에서는 내 OpenAI 또는 Claude 키를 써요. 페이지 텍스트는 질문할 때만 전송되며 모델 학습에 사용되지 않아요.

2.7에서 무엇이 새로워졌나요?

다른 언어로 된 페이지를 그 자리에서 번역하고, 링크도 그대로 작동해요. 웹 사이트의 텍스트 필드에서 페이지 내용을 고려한 ‘검사’와 ‘다시 쓰기’를 쓸 수 있고, Pro에서는 입력하는 동안 오류에 밑줄이 그어져요. 업무와 개인 생활을 나눠 두는 스페이스. 여러 채팅의 답변과 메모를 모아 비교하고 PDF로 저장하는 컬렉션. 새 페이지에서는 그 주제의 채팅이 알아서 열려요. 리마인더와 날짜는 Apple 미리 알림과 캘린더로 보낼 수 있어요. 메모에 페이지 스냅샷을 남길 수 있어요. 패널과 ✦는 어느 쪽에든 둘 수 있어요. Pro와 ‘내 키’ 요금제에서도 ‘비슷한 것 찾기’ 빠른 버전을 쓸 수 있어요. 그리고 ‘친구 초대’: 친구는 보너스 답변을 받고, 나는 Pro나 Ultra 할인을 받아요.

Ultra에는 Pro보다 무엇이 더 있나요?

답변과 페이지 전체를 소리 내어 읽어 주는 ‘듣기’(주당 30분), 어떤 페이지든 확인된 대안을 찾아 주는 ‘비슷한 것 찾기’ 풀 버전(주당 10회, Pro는 빠른 검색 5회), 그리고 20개가 아닌 최대 50개 페이지 지켜보기예요. Pro에서 바꾸면 바로 시작되고, Pro의 남은 기간은 Apple이 환불해요.

모든 웹 사이트에서 작동하나요?

일반 웹 사이트에서는 네. Safari는 일부 페이지(시작 페이지, App Store 페이지, 경우에 따라 PDF)를 확장 프로그램이 읽지 못하게 해요. 그런 곳에서도 일반적인 질문은 할 수 있어요.
