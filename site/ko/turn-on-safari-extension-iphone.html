iPhone·iPad에서 Safari 확장 프로그램 켜는 법

2026년 11월 업데이트 · ContextFlow 개발자가 씀

Safari 확장 프로그램을 설치했는데 페이지에 아무것도 안 보여요. 거의 항상 Safari가 답을 하나 더 기다리고 있는 거예요. 단계는 어떤 확장 프로그램이든 같아요. 제가 만드는 ContextFlow를 예로 들게요.

iPhone의 Safari에서 바로

  1. 아무 웹 사이트나 열고 주소 막대에서 페이지 메뉴 버튼을 탭하세요.
  2. ‘확장 프로그램 관리’를 탭하고 ContextFlow를 켜세요.
  3. 페이지 메뉴로 돌아와 ContextFlow를 탭한 다음 ‘항상 허용’을 선택하고, 이어서 ‘모든 웹 사이트에서 항상 허용’을 선택하세요.

iPad의 Safari에서 바로

iPad에서는 확장 프로그램이 페이지 메뉴에 없어요. 주소 옆의 퍼즐 조각 버튼 안에 있어요.

  1. 아무 웹 사이트나 열고 주소 옆의 퍼즐 조각 버튼을 탭하세요.
  2. ‘확장 프로그램 관리’를 탭하고 ContextFlow를 켜세요.
  3. 퍼즐 조각 버튼을 다시 탭한 다음 ContextFlow를 탭하고, ‘항상 허용’을 선택한 다음 ‘모든 웹 사이트에서 항상 허용’을 선택하세요.

설정에서

  1. 설정 앱을 열고 앱 › Safari › 확장 프로그램 › ContextFlow로 이동하세요.
  2. 켜고 ‘모든 웹 사이트’를 ‘허용’으로 설정하세요.
  3. Safari로 돌아와 페이지를 새로고침하세요.

켰는데 버튼이 없나요?

  • Safari가 아직 묻고 있어요. ‘모든 웹 사이트’가 ‘묻기’로 남아 있으면 버튼이 나타나지 않고, Safari의 질문은 iPhone에서는 페이지 메뉴에서, iPad에서는 주소 옆의 퍼즐 조각 버튼 안에서 기다리고 있어요. 거기서 ContextFlow에 ⚠ 표시가 있어요. 탭하고 ‘항상 허용’을 선택한 다음, 이어서 ‘모든 웹 사이트에서 항상 허용’을 선택하세요. iPad에서 주소 아래에 추가 권한을 요청하는 배너가 보이면 그것도 같은 질문이에요.
  • 확장 프로그램이 꺼져 있어요. ContextFlow가 페이지 메뉴(iPhone)에도, 퍼즐 조각 버튼 안(iPad)에도 아예 없어요. 거기서 ‘확장 프로그램 관리’를 탭해 켜세요.
  • 개인정보 보호 브라우징. 허용한 경우에만 확장 프로그램이 작동해요: 설정 › 앱 › Safari › 확장 프로그램 › ContextFlow › 개인정보 보호 브라우징에서 허용.
  • 확장 프로그램이 작동하지 않는 페이지. Safari는 시작 페이지, App Store 페이지 등 몇몇 페이지에서 확장 프로그램을 막아요. 일반 웹 사이트를 여세요.

Mac에서는

  • Safari › 설정 › 확장 프로그램에서 ContextFlow를 체크하고 모든 웹 사이트에서 허용하세요.
  • 그런 다음 도구 막대에서 ContextFlow를 클릭하거나 Control-Shift-E를 누르세요.

‘모든 웹 사이트에서 항상 허용’은 안전한가요?

Safari는 확장 프로그램이 무슨 일을 하는지 알 수 없기 때문에 모든 확장 프로그램에 같은 경고를 보여 줘요. ContextFlow는 무언가를 물어볼 때만 페이지를 읽고, 페이지 텍스트는 제 서버에 보관되지 않아요. 사이트별로 허용할 수도 있어요. 그러면 ✦는 그 사이트에서만 나타나요.

자주 묻는 질문

Safari 확장 프로그램은 어디에 있나요?

iPhone에서는 페이지 메뉴에 있어요. 읽기 도구와 번역도 들어 있는 주소 막대의 버튼이에요. iPad에서는 주소 옆의 퍼즐 조각 버튼 안에 있어요.

앱을 먼저 열어야 하나요?

확장 프로그램은 Safari에서도 설정에서도 켤 수 있어요. 구독 중이라면 구독이 확장 프로그램에 전달되도록 ContextFlow 앱을 한 번 열어 주세요.

켰는데도 아무것도 안 보여요.

페이지를 새로고침하세요. 그래도 ✦가 안 보이면 iPhone에서는 페이지 메뉴를, iPad에서는 퍼즐 조각 버튼을 여세요. 거기서 ContextFlow에 ⚠ 표시가 있다면 Safari가 아직 허용 여부를 묻고 있는 거예요.

iPad에서도 되나요?

네. iPad에서는 확장 프로그램이 페이지 메뉴 대신 주소 옆의 퍼즐 조각 버튼 안에 있어요. 나머지는 같아요.
