iPhone·iPad에서 Safari 확장 프로그램 켜는 법

2026년 11월 업데이트 · ContextFlow 개발자가 씀

Safari 확장 프로그램을 설치했는데 페이지에 아무것도 안 보여요. 거의 항상 아직 웹 사이트에서 허용되지 않았기 때문이에요. 단계는 어떤 확장 프로그램이든 같아요. 제가 만드는 ContextFlow를 예로 들게요.

iPhone에서

주소 막대의 페이지 메뉴 → ContextFlow → '항상 허용…' → '모든 웹사이트에서 항상 허용' 순서로 탭하세요.

'1일 동안 허용'은 고르지 마세요. 내일이면 ✦가 다시 사라져요.

또는 설정에서:

  1. 설정 앱을 열고 앱 → Safari(ContextFlow 아님) → 확장 프로그램 → ContextFlow로 이동하세요.
  2. 권한에서 '모든 웹 사이트'를 '허용'으로 설정하세요. 대신 웹 사이트 목록이 보이면 목록의 모든 항목을 '허용'으로 설정하세요.
  3. Safari로 돌아가 페이지를 새로고침하고 ✦를 탭하세요.

iPad에서

주소 옆의 퍼즐 조각 버튼 → ContextFlow → '항상 허용…' → '모든 웹사이트에서 항상 허용' 순서로 탭하세요.

'1일 동안 허용'은 고르지 마세요. 내일이면 ✦가 다시 사라져요.

또는 설정에서:

  1. 설정을 열고 왼쪽의 앱 → Safari(ContextFlow 아님) → 확장 프로그램 → ContextFlow로 이동하세요.
  2. 권한에서 '모든 웹 사이트'를 '허용'으로 설정하세요. 대신 웹 사이트 목록이 보이면 목록의 모든 항목을 '허용'으로 설정하세요.
  3. Safari로 돌아가 페이지를 새로고침하고 ✦를 탭하세요.

앱 목록에서 ContextFlow가 아니라 Safari를 선택하세요. ContextFlow도 목록에 있지만, 그 페이지에는 확장 프로그램 스위치가 없어요.

켰는데 버튼이 없나요?

  • ‘모든 웹 사이트’가 아직 ‘묻기’예요. 위에서처럼 설정에서 ‘허용’으로 바꾸고 페이지를 새로고침하세요.
  • 개인정보 보호 브라우징. 허용한 경우에만 확장 프로그램이 작동해요: 설정 › 앱 › Safari › 확장 프로그램 › ContextFlow › 개인정보 보호 브라우징에서 허용.
  • 확장 프로그램이 작동하지 않는 페이지. Safari는 시작 페이지, App Store 페이지 등 몇몇 페이지에서 확장 프로그램을 막아요. 일반 웹 사이트를 여세요.

Mac에서는

  • Safari › 설정 › 확장 프로그램에서 ContextFlow를 체크하고 모든 웹 사이트에서 허용하세요.
  • 그런 다음 도구 막대에서 ContextFlow를 클릭하거나 Control-Shift-E를 누르세요.

모든 웹 사이트에서 허용해도 안전한가요?

Safari는 확장 프로그램이 무슨 일을 하는지 알 수 없기 때문에 모든 확장 프로그램에 같은 경고를 보여 줘요. ContextFlow는 무언가를 물어볼 때만 페이지를 읽고, 페이지 텍스트는 제 서버에 보관되지 않아요. 사이트별로 허용할 수도 있어요. 그러면 ✦는 그 사이트에서만 나타나요.

자주 묻는 질문

Safari 확장 프로그램은 어디에 있나요?

설정은 설정 앱의 앱 → Safari → 확장 프로그램에 있어요. Safari 안에서는 iPhone의 경우 주소 막대의 페이지 메뉴에, iPad의 경우 주소 옆의 퍼즐 조각 버튼 안에 있어요.

앱을 먼저 열어야 하나요?

아니요. 확장 프로그램은 설정에서 켜요. 구독 중이라면 구독이 확장 프로그램에 전달되도록 ContextFlow 앱을 한 번 열어 주세요.

켰는데도 아무것도 안 보여요.

설정 → 앱 → Safari → 확장 프로그램 → ContextFlow를 열고 ‘모든 웹 사이트’가 ‘허용’으로 설정되어 있는지 확인한 다음 페이지를 새로고침하세요.

iPad에서도 되나요?

네. 설정에서의 단계는 같아요. iPad에서는 앱이 왼쪽 목록에 있어요.
